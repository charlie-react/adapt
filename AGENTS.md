# ADAPT — Project Instructions

I'm building ADAPT to make learning more accessible without lowering what learners are expected to learn.

Core principle: ADAPT changes how learning happens, not what the learner is expected to learn.

# What matters to me
Preserve the source. Keep the original meaning, facts, examples, numbers, equations and learning objectives intact. Never invent missing information.
Accessibility is fundamental. Consider keyboard navigation, screen readers, Read Aloud, voice interaction and different ways of accessing information from the start.
Keep it human. ADAPT should feel like a learning accommodation, not a generic chatbot or PDF summarizer.

# How I want to build
This is an MVP, so prioritize a reliable, demonstrable core experience over unnecessary features.
Keep the code modular and understandable, but don't over-engineer for hypothetical future needs.
Treat uploaded materials and AI outputs carefully. Preserve source evidence, validate outputs and handle failures honestly.
Protect API keys. Don't expose secrets or send unnecessary personal data to external services.
Keep the interface lightweight, responsive and usable on different devices and with limited connectivity.
